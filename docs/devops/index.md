# DevOps

Containerization, orchestration, and delivery pipelines: how a Python
backend service goes from source code to a running, scalable, safely
deployed process.

## Sections

- [Docker](docker/index.md) — images, containers, Dockerfiles, volumes,
  networks, Compose, and multi-stage builds.
- [Kubernetes](kubernetes/index.md) — Pods, Deployments, Services,
  ConfigMaps, Secrets, Ingress, probes, resource management, scaling, and
  `kubectl`.
- [Helm](helm/index.md) — charts, templates, values.yaml, helpers,
  releases, and secrets/configuration management.
- [CI/CD](cicd/index.md) — Git workflows/branching, pipeline stages,
  Docker builds and image registries, and deployment/rollback
  strategies.
