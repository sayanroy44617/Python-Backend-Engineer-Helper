# Kubernetes

Running containerized services in production at scale: the core
objects (Pods, Deployments, Services), configuration and secrets
management, external routing via Ingress, resource management and
scaling, and the `kubectl` workflows for day-to-day operation and
troubleshooting.

This section assumes familiarity with
[Docker](../docker/index.md) — Kubernetes schedules and manages the same
containers/images covered there, adding orchestration on top rather than
replacing container concepts.
