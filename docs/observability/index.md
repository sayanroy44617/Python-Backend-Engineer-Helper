# Observability

How to understand what a running system is actually doing: structured
logging, metrics (Prometheus), distributed tracing (OpenTelemetry), and
the health checks/alerting that turn all of it into actionable signals.

FastAPI-specific request logging middleware is covered in
[Middleware and Exception Handling](../fastapi/04-middleware-and-exception-handling.md)
— this section focuses on what to log/measure/trace and why, rather than
repeating the middleware wiring mechanics.
