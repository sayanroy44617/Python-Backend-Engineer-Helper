# Python Packaging

Notes on managing environments, dependencies, and distributable packages —
the tooling layer around the Python language itself.

This section assumes the import/module system covered in
[Modules and Packages](../python/04-modules-and-packages.md); it focuses on
how projects are set up, installed, and distributed rather than how Python
resolves imports at runtime.

- [pyproject.toml and Dependency Management](02-pyproject-and-dependency-management.md) — pyproject.toml, dependency management, versioning
- [Package Structure and Editable Installs](03-package-structure-and-editable-installs.md) — distributable package layout, editable installs
